### What is LAPS

- Windows local administrator password solution is a feature that automatically manages and backs up the password of a local administrator account on your Microsoft Entra-joined or Windows Server Active Directory-joined devices.
- It can also manage and back up the Directory Services Restore Mode (DSRM) account password on your Windows Server Active Directory domain controllers.
	- An authorized administrator can retrieve the DSRM password and use it.
